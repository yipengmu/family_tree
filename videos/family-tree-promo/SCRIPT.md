# 20-second promo script

**Format:** 1920×1080 landscape
**Audio:** silent kinetic typography; optional voiceover can be added later

## On-screen story

1. 0–4s — “有些故事，值得被留下。”
2. 4–9s — “看家谱，名字不再只是名字。”
3. 9–15s — “续家谱，把记忆一代代接上。”
4. 15–20s — “谱里｜年轻人的第一份家谱” + “看家谱，续家谱，管家谱。”
